# Супер Бджолы

Детская браузерная игра: пчёлы охраняют мёд Королевы от зелёных жуков, серого медведя, дяди с усыпителем и Короля Жуков. Сюжет придумал ребёнок.

Играть: https://mariaukrainets5-dot.github.io/super-bdzholy/

- `index.html` — игра (один файл, canvas и JS).
- `art/` — картинки и озвучка, сделаны в Higgsfield; `make-art.py` готовит их из оригиналов.
- `build-site.py` собирает `docs/` для GitHub Pages: после правки `index.html` запустить его, закоммитить и запушить.
